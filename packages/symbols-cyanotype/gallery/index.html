Cyanotype symbol pack

Sixteen photogram symbols from Abyssal Tide, drawn as SVG and rasterised at load. Each one carries its own win motion, so a new game can reuse the board and swap the pack.

Big-win character (Spine)

Using the pack

const pack = await createCyanotypePack({
  mono: 'IBM Plex Mono',
  stencil: 'Big Shoulders Stencil Display',
});
const symbol = new SymbolView(pack); // from @slotkit/board
symbol.set({ s: 'NAUTILUS' });
symbol.startWin();                   // motion preset "roll"
