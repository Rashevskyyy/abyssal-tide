# Abyssal Tide · Список анімацій

Тривалості — для швидкості «Звичайна» (GDD §4); на Quick і Turbo вони пропорційно коротші (`SPEED_PROFILES` у `@slotkit/core`).
Колонка «Reduced motion» описує поведінку з увімкненим зменшеним рухом (системне налаштування або меню).

Усі анімації написані процедурно (GSAP + PixiJS), без Spine. Анімації барабанів і символів живуть у пакеті `@slotkit/board`; кожен символ отримує від пака пресет руху (`pulse`, `swing`, `float`, `roll`, `flicker`, `unfold`, `soft`), тож нова гра з іншим паком отримає ті самі анімації без коду. Усі пресети можна подивитися на сторінці-галереї пака (`npm run gallery`). Візуальна мова — ціанотипія: замість неонового світіння біла «засвітка», виграші й очікування позначає кораловий олівець, банери — гумові штампи. Розділ «Далі» наприкінці — що варто зробити на справжніх асетах.

## Далі (на продакшн-асетах)

- Spine-анімації символів замість трансформацій цілої картинки: стрілка компаса окремо від корпусу, бульбашки з клапана шолома, щупальця наутилуса, полум’я ліхтаря як частинки, розгортання карти по кадрах.
- Інтро-персонаж або сцена занурення водолаза для входу в Free Dives.
- Окрема анімація відкриття мушлі (стулки на шарнірі) замість заміни текстури.
- «Проявка» символів при посадці: відбиток з’являється з білого в синє за кілька кадрів, як у ванночці з водою.
- Частинки-монети або перли при великому виграші з фізикою (ParticleContainer у Pixi v8).
- Анімація виграшу для кожної довжини комбінації (3/4/5) з наростанням ефекту.
